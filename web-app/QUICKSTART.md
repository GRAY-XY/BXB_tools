# 🚀 快速开始指南

> 5 分钟快速启动 BXB Student Web 应用

## 步骤 1：安装依赖

```bash
cd web-app
npm install
```

## 步骤 2：启动开发服务器

```bash
npm run dev
```

你会看到：
```
[0] 🚀 BXB Student Web Server running at http://localhost:3000
[1] ➜  Local:   http://localhost:5173/
```

## 步骤 3：打开浏览器

访问：http://localhost:5173

## 步骤 4：登录

使用你的班学帮账号登录即可！

## 🎨 界面预览

### 登录页面
- 输入账号密码
- 点击登录按钮
- 等待几秒完成登录（会使用 Playwright 自动登录）

### 工作台
登录后默认显示工作台，包含：

- ⚡ 快速操作按钮

### 侧边栏导航
- 📊 工作台
- 📝 作业
- 📅 课程
- 🔔 通知
- 💬 私信
- 📁 文件
- ⚙️ 设置

## 📝 常见操作

### 切换课程
1. 点击工具栏的"科目"下拉框
2. 选择想要的课程
3. 页面自动刷新数据

### 查看作业详情
1. 进入"作业"页面
2. 点击任一作业卡片
3. 查看作业内容、附件、提交状态

### 发送私信
1. 进入"私信"页面
2. 点击联系人
3. 在底部输入框输入消息
4. 点击"发送"按钮（功能待完成）

### 管理文件
1. 进入"文件"页面
2. 查看工作区所有文件
3. 点击操作按钮进行预览、下载、删除

## 🐛 遇到问题？

### 登录失败
- 检查账号密码是否正确
- 查看浏览器控制台的错误信息
- 确认后端服务已启动

### 数据加载失败
- 检查网络连接
- 确认 API 服务正常（http://localhost:3000）
- 查看浏览器控制台的网络请求

### 页面显示异常
- 尝试刷新页面（F5）
- 清除浏览器缓存
- 检查浏览器控制台的错误信息

## 💡 开发提示

### 热更新
保存文件后，页面会自动刷新，无需手动刷新浏览器。

### 调试技巧
1. 打开浏览器开发者工具（F12）
2. 查看 Console 标签的日志
3. 查看 Network 标签的网络请求
4. 使用 Vue DevTools 或 React DevTools（虽然这是原生 JS，但可以看 DOM）

### 代码结构
```
src/
├── api/         # API 调用封装
├── components/  # UI 组件
├── pages/       # 页面组件
├── app.js       # 应用逻辑
├── main.js      # 应用入口
└── style.css    # 全局样式
```

### 添加新功能
1. 阅读 [README.md](./README.md) 的"开发指南"章节
2. 查看 [TODO.md](./TODO.md) 选择任务
3. 按照组件模式开发
4. 测试功能后提交代码
