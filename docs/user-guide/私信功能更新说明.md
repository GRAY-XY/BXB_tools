# 私信功能更新说明

## 🎉 新功能：私信

班学帮学生端现已支持私信功能！您可以直接在应用内与老师进行私信沟通。

### ✨ 主要特性

- 📬 **联系人列表** - 查看所有与老师的私信联系人
- 💬 **消息会话** - 查看与老师的历史消息（最多50条）
- 📤 **发送消息** - 发送文字消息给老师
- 🔔 **未读提醒** - 显示未读消息数量，打开会话自动清除
- 🎨 **主题集成** - 使用课程颜色作为主题，美观统一
- 📱 **响应式** - 自动适配窗口大小，提供最佳布局


### 🚀 如何使用

1. **进入私信页面**
   - 点击左侧导航栏的"私信"图标（💬）
   - 如有未读消息，会显示红色数字徽章

2. **查看消息**
   - 点击联系人查看与该老师的消息历史
   - 接收的消息显示在左侧（灰色）
   - 发送的消息显示在右侧（彩色）

3. **发送消息**
   - 在底部输入框输入文字
   - 点击"发送"按钮
   - 消息会立即出现在会话中

4. **刷新联系人**
   - 点击联系人列表右上角的🔄按钮
   - 获取最新的消息和未读数

### ⚠️ 当前限制

- 仅支持文字消息（暂不支持图片、文件）
- 消息历史固定显示最近50条
- 需要手动刷新才能看到新消息（暂无实时推送）
