# BXB Student 隐私说明（草案）

更新日期：2026 年 4 月 27 日

本说明用于帮助你了解 BXB Student 在桌面端会处理哪些信息、这些信息的用途，以及哪些内容会保存在你的本地设备上。

## 1. 处理的数据范围

本软件在你使用过程中，可能处理以下信息：

- 登录账号与密码
- 登录会话信息与访问令牌
- 姓名、年级、课程、课表、作业、等级、提醒设置
- 登录邮箱 / 登录名
- 作业详情、附件信息、提交记录
- 你主动选择上传或下载的本地文件路径
- 用于排查问题的基础运行日志
- 账号登记与访问控制所需的最小识别信息

## 2. 数据用途

上述信息仅用于实现以下功能：

- 登录班学帮平台
- 拉取并展示课表、作业和课程信息
- 下载作业附件
- 提交作业内容与上传文件
- 保存主题、提醒、排序和记住密码等本地偏好
- 记录基础错误日志，方便排查登录失败、下载失败或接口异常
- 维护用户登记、版本控制和异常行为处置

## 3. 本地存储

本软件会在你的设备本地保存部分数据，包括但不限于：

- 登录状态缓存
- 记住密码配置
- 提醒设置与外观设置
- 下载的附件文件
- 运行日志
- 用户登记缓存与待同步记录

其中，附件默认下载到：

`~/Downloads/BXB Student/`

运行日志默认保存在：

`~/Library/Application Support/BXB Student/logs/`

## 4. 关于记住密码

如果你启用“记住账号和密码”，相关信息将保存在当前设备本地，用于下次快速登录。该功能会提升便利性，但也会带来本地泄露风险。请不要在公共设备或他人设备上长期启用此功能。

## 5. 第三方平台依赖

本软件是第三方桌面客户端，数据来源依赖班学帮平台及其当前账号权限。本软件本身不决定教师布置内容、成绩结果或学校官方记录，展示内容应以学校和原平台信息为准。

## 6. 日志说明

本软件会记录必要的运行日志，例如桥接调用失败、更新检查失败、启动异常等。日志用于排查问题，不应用于传播或公开分享带有敏感内容的信息。在反馈问题前，请先自行确认日志中是否包含不希望外传的个人信息。

## 7. GitHub 登记与远程控制

在软件维护配置启用时，桌面端可能在用户登录成功后登记以下最小信息到维护方管理的 GitHub 仓库文件中：

- 姓名
- 登录邮箱 / 登录名
- 用户 ID
- 平台
- 应用版本
- 首次出现时间与最近登录时间

同时，软件会从 GitHub 策略文件读取最低支持版本、封禁名单和锁定文案，用于在发现异常行为、滥用风险或版本过旧时限制软件继续使用。

## 8. 用户控制

你可以通过以下方式管理本地信息：

- 关闭“记住账号和密码”
- 退出登录
- 清理本地下载目录
- 删除本地日志目录
- 卸载软件后手动清理保存在用户目录中的数据
