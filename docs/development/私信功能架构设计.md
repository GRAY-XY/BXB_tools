# 私信功能架构设计文档

## 概述
本文档描述班学帮学生端私信功能的技术架构和实现细节。

## 数据流

### 1. 加载联系人列表
```
User Action (点击私信标签)
  ↓
MessagesPage → onSectionSelected('messages')
  ↓
AppController.ensurePrivateMessagesLoaded()
  ↓
AppController.loadPrivateContacts()
  ↓
DesktopBridge.listPrivateContacts()
  ↓
node_bridge.js 'list-private-contacts'
  ↓
BanxuebangClient.listPrivateMessageContacts()
  ↓
GET /gateway/bxb/priv-msg/user/{userId}/contact-list
  ↓
Response: { contacts: [...], count: N }
  ↓
Transform to List<PrivateContact>
  ↓
AppController.privateContacts = result
  ↓
UI Update (notifyListeners)
```

### 2. 加载消息会话
```
User Action (点击联系人)
  ↓
MessagesPage._selectContact(contact)
  ↓
AppController.loadMessageThread(contact)
  ↓
DesktopBridge.getPrivateMessageThread(contact)
  ↓
node_bridge.js 'get-private-thread'
  ↓
BanxuebangClient.getPrivateMessageThread(contact, {size: 50})
  ↓
GET /gateway/bxb/priv-msg-content/class/{classId}/page-query
  ↓
Response: { messages: [...], page: {...} }
  ↓
Transform to List<PrivateMessage>
  ↓
AppController.privateMessages = result
AppController.selectedPrivateContact = contact
Clear unreadNum for this contact
  ↓
UI Update (notifyListeners)
```

### 3. 发送消息
```
User Action (点击发送)
  ↓
MessagesPage._sendMessage()
  ↓
AppController.sendPrivateMessage(contact, content)
  ↓
DesktopBridge.sendPrivateMessage(contact, content)
  ↓
node_bridge.js 'send-private-message'
  ↓
BanxuebangClient.sendPrivateMessageText(contact, content)
  ↓
POST /gateway/bxb/priv-msg-content/send
  ↓
Response: { sent: true, message: {...} }
  ↓
Transform to PrivateMessage
  ↓
AppController.privateMessages.add(sentMessage)
Update contact.lastContent and lastTime
  ↓
UI Update (notifyListeners)
```

## 数据模型

### PrivateContact (Dart)
```dart
class PrivateContact {
  final String id;              // 联系人记录ID
  final String classId;         // 班级ID
  final String className;       // 班级名称
  final String peerId;          // 对方用户ID
  final String peerName;        // 对方姓名
  final String peerType;        // 对方类型 ("T"=老师, "S"=学生)
  final int unreadNum;          // 未读消息数
  final String lastTime;        // 最后消息时间
  final String lastContent;     // 最后消息内容
  final String? courseName;     // 课程名称
  final String? courseColor;    // 课程颜色（用于主题）
  final JsonMap? raw;           // 原始数据（用于传递给后端）
}
```

### PrivateMessage (Dart)
```dart
class PrivateMessage {
  final String id;              // 消息ID
  final String content;         // 消息内容
  final String senderId;        // 发送者ID
  final String senderName;      // 发送者姓名
  final String receiverId;      // 接收者ID
  final String receiverName;    // 接收者姓名
  final String createTime;      // 创建时间
  final String? contentType;    // 内容类型 ("T"=文字)
  final int? readFlag;          // 已读标志 (0=未读, 1=已读)
}
```

## 状态管理

### AppController 状态变量
```dart
// 数据状态
List<PrivateContact> privateContacts = [];
PrivateContact? selectedPrivateContact;
List<PrivateMessage> privateMessages = [];

// 加载状态
bool loadingPrivateContacts = false;
bool loadingPrivateMessages = false;
bool sendingPrivateMessage = false;

// 懒加载标志
bool _privateMessagesRequested = false;
```

### 状态更新流程
1. **用户点击私信标签**
   - `_privateMessagesRequested` 设为 true
   - 如果 `privateContacts` 为空，调用 `loadPrivateContacts()`

2. **加载联系人**
   - `loadingPrivateContacts = true`
   - 调用 API
   - 更新 `privateContacts`
   - `loadingPrivateContacts = false`
   - `notifyListeners()`

3. **选择联系人**
   - 设置 `selectedPrivateContact`
   - `loadingPrivateMessages = true`
   - 调用 API
   - 更新 `privateMessages`
   - 清除该联系人的 `unreadNum`
   - `loadingPrivateMessages = false`
   - `notifyListeners()`

4. **发送消息**
   - `sendingPrivateMessage = true`
   - 调用 API
   - 将新消息添加到 `privateMessages`
   - 更新联系人的 `lastContent` 和 `lastTime`
   - `sendingPrivateMessage = false`
   - `notifyListeners()`

## 错误处理

### 1. 网络错误
- 在 `AppController` 的 catch 块中捕获
- 通过 `_setBanner(errorText, isError: true)` 显示错误
- 顶部横幅显示，用户可手动关闭

### 2. 空状态
- 无联系人：显示"暂无私信联系人"
- 无消息：显示"暂无消息记录"
- 未选中联系人：显示"选择一个联系人开始对话"

### 3. 验证错误
- 空消息内容：在发送前拦截，显示错误提示
- 无效联系人：API层抛出异常，UI显示错误

## 性能优化

### 1. 懒加载
- 只在用户首次点击私信标签时加载联系人
- 使用 `_privateMessagesRequested` 标志避免重复加载

### 2. 缓存页面实例
```dart
final Map<_ShellSection, Widget> _builtPages = {};

Widget _pageFor(_ShellSection section) {
  return _builtPages.putIfAbsent(section, () {
    // 构建并缓存页面实例
  });
}
```

### 3. 局部重建
- 使用 `ListenableBuilder` 只重建需要更新的部分
- 避免全页面重建

### 4. 状态管理优化
- 使用 `notifyListeners()` 而不是 `setState()`
- 只在数据真正变化时才通知监听者

## 安全考虑

### 1. 输入验证
- 前端验证：检查消息内容非空
- 后端验证：`banxuebang-client.js` 中的 `trim()` 和非空检查

### 2. 数据传输
- 所有API调用通过HTTPS
- 会话管理使用现有的认证机制

### 3. 敏感数据
- 不在客户端永久存储消息内容
- 联系人原始数据 (`raw`) 仅用于API调用传递
