## 🛠️ 技术亮点

### 1. 无框架依赖
- 纯 JavaScript 实现，没有 React/Vue 等框架
- 轻量级，加载速度快
- 易于理解和维护

### 2. 模块化设计
- 组件、页面、API 清晰分离
- 单一职责原则
- 便于扩展和测试

### 3. 状态管理
- 简单的观察者模式
- 集中式状态管理
- 自动 UI 更新

### 4. 业务逻辑复用
- 直接使用现有的 `banxuebang-client.js`
- 无需重写业务逻辑
- 保持与桌面版一致

### 5. 开发体验
- Vite 提供热模块替换（HMR）
- 保存即刷新
- 开发效率高

## 💼 部署建议

### 开发环境
当前配置已可用于本地开发：
```bash
npm run dev
```

### 生产部署
推荐方案：

**方案 A：Vercel + 自托管 API**
- 前端：部署到 Vercel（免费）
- 后端：部署到 VPS 或 Railway

**方案 B：一体化部署**
- 使用 Node.js 同时提供静态文件和 API
- 部署到 Heroku、Railway 或 VPS

**方案 C：Docker 容器化**
- 创建 Dockerfile
- 使用 Docker Compose 管理服务
- 部署到任何支持 Docker 的平台
