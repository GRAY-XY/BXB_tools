# BXB Student 1.0.2

## Highlights

- Added the new Flutter desktop app under `UI/banxuebang_flutter/` as the current release surface for macOS and Windows.
- Bundled the runtime payload directly into the packaged app, including `node`, production `node_modules`, Playwright Chromium, local release notes, and legal docs.
- Added a self-contained macOS `.pkg` build flow that installs `BXB Student.app` without requiring the repository to stay on disk.
- Added Windows installer handoff scripts and a matching GitHub Actions artifact workflow so a Windows teammate can build and verify the release from the same commit.
- Improved installed-app runtime discovery and session storage so desktop builds use the local app-support directory instead of repo-relative paths.

## Included macOS asset

- `BXB_Student_macOS_v1.0.2.pkg`

## Notes

- The macOS package in this release is built as `arm64` from the current macOS host environment.
- The package bundles a local `node` runtime and Playwright Chromium so browser login does not require a separate Node install.
- The package is not notarized in this release.
- The Windows installer is expected to be added after a Windows-side packaging pass from the same `v1.0.2` source tree.
