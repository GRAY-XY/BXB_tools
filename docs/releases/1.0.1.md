# BXB Student 1.0.1

## Highlights

- Rebuilt the desktop app around the new `pywebview` shell instead of the older UI.
- Added credential login with optional remembered credentials.
- Added a cleaner student dashboard focused on grade, schedule, and homework flow.
- Expanded homework loading across all subjects instead of only the current subject.
- Added sorting controls for homework lists and improved detail rendering.
- Added independent homework reminders and class reminders in settings.
- Added in-app support surfaces for version display, update checks, local logs, downloads folder access, release notes, user agreement, and privacy notice.
- Added working attachment download from the homework detail view.
- Added a GitHub-backed desktop control policy, optional user registry sync, and app lock support for abnormal-behavior handling.

## Included macOS asset

- `BXB_Student_macOS_v1.0.1.pkg`

## Notes

- The macOS package bundles a local `node` runtime and Playwright Chromium so browser-based login can run without a separate Node install.
- The package is not notarized in this release.
- The packaged app now bundles the local `docs/` set used by the Settings support area.
