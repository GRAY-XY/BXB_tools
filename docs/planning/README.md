## 🛠️ 技术栈

### 前端
- **框架**: 原生 JavaScript（轻量、快速）
- **构建**: Vite（HMR、ES Modules）
- **样式**: CSS Variables（主题系统）
- **图表**: Chart.js（可视化）

### 后端
- **框架**: Express.js
- **会话**: express-session
- **文件**: multer（上传）
- **业务**: banxuebang-client.js（复用）

### 部署
- **前端**: Vercel（推荐）
- **后端**: Railway / Render
- **备选**: Docker + VPS

## 💡 关键决策

### 为什么保持原生 JS？
1. ✅ 当前代码已有 75% 完成度
2. ✅ 轻量级，加载速度快
3. ✅ 易于理解和维护
4. ✅ 无框架锁定

### 为什么分三个阶段？
1. **Phase 1**: 确保基本可用
2. **Phase 2**: 提升用户体验
3. **Phase 3**: 锦上添花

**原则**: MVP 优先，快速迭代

### 为什么选择 Vercel + Railway？
1. ✅ 简单易用，自动部署
2. ✅ 免费层足够使用
3. ✅ 性能优秀
4. ✅ 文档完善
