# Complete Tool Catalog

Generated by `release/scripts/sync-agent-skill.mjs`; do not edit this catalog or the vendored `runtime/` manually.

52 callable tools: all 47 shared backend tools plus 5 standalone adapters. Exact JSON Schemas are in [tools.json](tools.json). Inspect one schema with `node scripts/bxb.mjs describe TOOL`.

The package exposes every listed tool. Effect labels guide the calling agent; they are not a permission sandbox. Remote writes require authorization for the concrete destination and content. Draft delivery uses the reviewed preview's confirmation token and exact attachment selection. Local Python execution has a timeout, not a security sandbox.
